# 夢・目標の実API・RLS試験

対象：テストSupabase `imgearpizizqkutzrpuz` のみ。
結果：61項目成功、失敗0件。試験ユーザー4件と専用データは削除確認済み。

## 方法

承認を受けてAuth管理APIで合成ユーザー4件を作成した。有効会員A、有効なadminロールのB、停止会員、非会員として、各本人のパスワード認証で取得したJWTから実Data APIを操作した。未ログイン操作はPublishable keyのみで試験した。

メール宛先は `example.invalid`、パスワードはランダム生成。招待・再設定メールは送っていない。管理キーは合成データ準備、合成会員Aの停止、限定した状態確認、後片付けだけに使用した。証明書検証付きHTTPSと既存プロキシを使用し、SQLや既存Auth設定は変更していない。

合成目標は計28件（Aが25件、Bが2件、停止会員が1件）を用意した。停止会員の既存行だけは管理側で作成し、本人から拒否されることを確認した。
