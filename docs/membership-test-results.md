結果：実APIによる37項目が成功、失敗0件。試験用ユーザー・専用データの削除確認済み。

## 実行方法

- 承認を受けて、このクラウド環境からHTTPS経由で実施した。
- プロキシに登録された試験用キーを使用し、値はログやリポジトリに保存していない。
- Auth管理APIでランダムな識別子・パスワードの合成ユーザーを4件作成した。メール宛先には `example.invalid` を使用し、招待メール・パスワード再設定メールは送っていない。
- 4ユーザーそれぞれをパスワード認証し、取得した本人のJWTでData APIを呼び出した。JWTはメモリ内だけで使用した。
- 有効会員A、管理者ロールの有効会員B、停止会員、非会員を用意した。未ログインの操作も確認した。
- 管理キーは合成データの準備・Aの停止・結果確認・削除にだけ使った。利用者向けRLS試験の成功判定には使っていない。
